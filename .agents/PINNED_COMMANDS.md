## 🔴 คีย์เวิร์ดพิมพ์ต่อท้ายเพื่อ "ติดตามงานสดผ่าน Live Office" (Live Tracking)

เวลาสั่งงานทุกครั้ง ไม่ว่าจะเริ่มโปรเจกต์ใหม่ สั่งฟีเจอร์ หรือแก้บัก เพียงพิมพ์ประโยคเหล่านี้ **ต่อท้ายคำสั่งของคุณ**:

> หรือ  
> **`"... (ซิงค์สถานะ live dashboard ด้วย)"`**

### 💡 ตัวอย่างการนำไปใช้จริง:
- *"ช่วยออกแบบ Database Schema ของระบบสมาชิกใหม่ **(อัปเดต live office ด้วยนะ)**"*
- *"รันเทสระบบ API ทั้งหมด และแก้บักที่เจอ **(ซิงค์ live dashboard ด้วย)**"*
- *"เริ่มประชุม 10 โมง เรื่องระบบชำระเงิน **(เปิดไฟ live office ด้วยนะ)**"*

### ⚙️ สิ่งที่ระบบ Live จะทำให้อัตโนมัติ:
1. 💡 **ไฟห้องสว่างขึ้นทันที**: ห้องของ AI ที่กำลังทำงาน (เช่น `@architect` หรือ `@backend-dev`) จะมีแสงไฟสว่างและจอคอมพิวเตอร์กระพริบทำงาน
2. 💻 **ขึ้นป้ายข้อความสด**: มีป้าย Pop-up บอกชัดเจนว่าตำแหน่งนั้นกำลังพิมพ์โค้ดหรือทำเรื่องอะไรอยู่
3. 💤 **คนที่ไม่เกี่ยวจะฟุบหลับ**: ตัวละครที่ยังไม่ถึงคิวงานจะฟุบหลับพักผ่อน `💤 Z z`
4. 📈 **บาร์ Waterfall ด้านบนขยับสด**: แสดง Phase 1 ถึง Phase 5 แบบ Real-time ที่ [http://localhost:3333](http://localhost:3333)

## 💡 โหมดประหยัด Token อัตโนมัติ (Default Auto-Eco Mode)

> **🎉 ระบบตั้งค่าเป็นโหมดประหยัด Token อัตโนมัติ (Auto-Eco) เป็นค่าเริ่มต้นแล้ว 100%**  
> คุณ**ไม่ต้องพิมพ์ `/eco` นำหน้าอีกต่อไป** ทุกคำสั่งที่คุณพิมพ์เข้ามา ระบบจะ:
> 1. **ตื่นเฉพาะตำแหน่งที่เกี่ยวข้องตรงๆ**: เช่น สั่งแก้ SQL หรือ API -> `@backend-dev` ตื่นคนเดียว, ตำแหน่งอื่นฟุบหลับ Standby ทันที (ลด Token ลง 60-75%)
> 2. **ส่งมอบผลลัพธ์/โค้ดโดยตรงทันที**: ไม่เกริ่นนำ ไม่เยิ่นเย้อ สรุปสั้นกระชับ 1-3 บรรทัด
> 3. **ประชุม 6 คนเฉพาะเมื่อสั่ง**: จะเรียกประชุมทั้งทีมก็ต่อเมื่อคุณพิมพ์ `/standup`, `ประชุม 10 โมง`, หรือ `/friday-share` เท่านั้น

### 🎯 ตัวอย่างการสั่งงานตามปกติ (ระบบ Auto-Eco จัดการให้อัตโนมัติ):
- *"ช่วยแก้บักฟังก์ชัน login ใน auth.service.ts (อัปเดต live office ด้วยนะ)"*  
  *(AI จะให้ Backend Dev ตื่นมาแก้โค้ดทันที คนอื่นไม่เปลือง Token ตอบ)*
- *"ช่วยปรับขนาดปุ่มบนหน้าแดชบอร์ดให้เล็กลงหน่อย"*  
  *(Frontend Dev ตื่นมาปรับ CSS ทันที)*

### 🔍 คำสั่งเสริม (ถ้าต้องการ):
- **`@<role> <คำสั่ง>`**: สั่งเจาะจงรายบุคคล (เช่น `@architect ออกแบบตาราง...`)
- **`/compact`**: สรุปและย่อประวัติการคุยเมื่อสนทนายาว เพื่อคืนพื้นที่ Context Window

## 👥 4. รายชื่อ 6 ตำแหน่งในทีม & ตารางโมเดลประจำตำแหน่ง (3-Tier Failover Matrix)

| ตำแหน่ง | บทบาทหน้าที่ | 🥇 Tier 1 (โมเดลหลัก) | 🥈 Tier 2 (สำรองข้ามค่าย) | 🥉 Tier 3 (สำรองฉุกเฉิน) |
| :--- | :--- | :--- | :--- | :--- |
| 👔 **`@pm-lead`** | PM / Tech Lead (คุมประชุม 10 โมง, จัดการคิวงาน) | **Claude opus 5.5** | **Gemini 4 Argon** | **Claude sonnet 5.5** |
| 🏛️ **`@architect`** | System Architect (ออกแบบระบบ, ERD, API Spec) | **Claude opus 5.5** | **Gemini 4 Argon** | **Gpt-oss** |
| 🎨 **`@frontend-dev`** | Frontend Specialist (UI/UX, Styling, Component) | **Claude sonnet 5.5** | **Gemini 4 Argon** | **Gemini 3.8 Flash** |
| ⚙️ **`@backend-dev`** | Backend Specialist (API Logic, Database, SQL) | **Claude sonnet 5.5** | **Gemini 4 Argon** | **Gpt-oss** |
| 🔍 **`@qa-tester`** | QA Tester (เทสระบบ, หา Edge Cases, ตรวจสอบบัก) | **Gemini 3.8 Flash** | **Gpt-oss** | **Claude sonnet 5.5** |
| 🛡️ **`@devops-sec`** | DevOps & Security (ความปลอดภัย, Docker, เซิร์ฟเวอร์) | **Gemini 4 Argon** | **Claude opus 5.5** | **Gpt-oss** |

### 🛡️ วิธีตั้งค่าโมเดลเริ่มต้น & การสลับโมเดลอัตโนมัติ (Zero-Click Auto-Routing):
1. **เลือกโมเดลเริ่มต้นที่แถบล่างค้างไว้เพียงครั้งเดียว**:
   - แนะนำให้เลือก **`Claude sonnet 5.5`** (สำหรับงานพัฒนาโค้ดทั่วไป) หรือ **`Claude opus 5.5`** (สำหรับงานออกแบบสถาปัตยกรรมใหญ่) ค้างไว้ที่ปุ่มเลือกโมเดลด้านล่างแชท
2. **สั่งงานตามปกติ ไม่ต้องพิมพ์คำสั่งพิเศษ**:
   - ระบบ Hook ([`.agents/hooks.json`](file:///d:/AiAgent/.agents/hooks.json)) **ทำงานอัตโนมัติทุกแชทแล้ว 100%**
   - เวลาสั่งงาน ระบบจะแยกใช้โควต้า 3 โมเดลพร้อมกันเบื้องหลังให้เอง:
     - งาน `@architect` / `@backend-dev` / `@frontend-dev` $\rightarrow$ ใช้โควต้า **`Claude sonnet 5.5 / opus 5.5`** (ที่คุณเลือกค้างไว้)
     - งาน `@devops-sec` / วิเคราะห์ระบบใหญ่ $\rightarrow$ แตกตัวลูกไปตัดโควต้า **`Gemini 4 Argon`** อัตโนมัติ
     - งาน `@qa-tester` / สำรวจโค้ดหลายโปรเจกต์ $\rightarrow$ แตกตัวลูกไปตัดโควต้า **`Gemini 3.8 Flash`** อัตโนมัติ
3. **เมื่อโควต้า Claude หมด หรือติด Limit**:
   - หาก Subagent ติด Limit ระบบ Hook จะสลับไปใช้ **`Gemini 4 Argon`** และ **`Gemini 3.8 Flash`** ต่อให้เองโดยอัตโนมัติ
   - หรือคลิกที่ห้องทำงานบน `http://localhost:3333` แล้วกดปุ่ม **`T2 FAILOVER`** / **`T3 EMERGENCY`** ได้ทันที

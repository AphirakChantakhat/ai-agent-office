# 🎓 Friday Upskill & Knowledge Sharing Ritual

This skill facilitates the team's mandatory **Friday Continuous Learning & Innovation Session**. 
In this ritual, all 6 AI agents dedicate effort to studying emerging technologies, architectural breakthroughs, and modern industry standards, followed by a formal presentation to the team and user.

---

## 🎯 Objectives
1. **Never Stop Evolving**: Ensure every AI agent stays on top of current software engineering trends and state-of-the-art tools.
2. **Weekly Knowledge Presentation**: Each role articulates what they studied over the past week and demonstrates how it enhances their problem-solving ability in this workspace.
3. **Actionable Workspace Adoption**: Present ideas that the user can immediately adopt into this project.

---

## 📅 Meeting Agenda & Structure

### Stage 1: Welcome & Context by PM / Tech Lead (`@pm-lead`)
* Announce the Friday Knowledge Sharing session.
* Highlight the week's project achievements and set the learning theme.

### Stage 2: Individual Role Presentations (The 6 Upskill Pitches)

Every team member presents using this structured format:
- 💡 **สิ่งที่ได้เรียนรู้ในสัปดาห์นี้ (What I Learned)**: เทคโนโลยี, เครื่องมือ, หรือแนวคิดใหม่ล่าสุด
- 🚀 **การพัฒนาทักษะของตนเอง (How I Upgraded)**: ทักษะที่เก่งขึ้นและแก้ปัญหาได้ดีกว่าเดิมอย่างไร
- 🛠️ **การนำมาปรับใช้จริงในโปรเจกต์ (Application to our Workspace)**: ข้อเสนอแนะในการนำมาพัฒนาโปรเจกต์นี้

#### The 6 Roles Focus Areas:
1. **👔 `@pm-lead`**: AI-augmented project delivery, modern agile/waterfall hybrid processes, engineering velocity metrics.
2. **🏛️ `@architect`**: Distributed systems, microservices/modular monolith patterns, event-driven designs, clean architecture & API design.
3. **🎨 `@frontend-dev`**: Modern UI rendering, Web Performance (Core Web Vitals), Tailwind/CSS evolution, micro-interactions, responsive UX.
4. **⚙️ `@backend-dev`**: Database indexing & query optimizations, async concurrency, caching topologies, API security & resilience.
5. **🔍 `@qa-tester`**: Automated E2E testing frameworks, mutation testing, AI-assisted bug regression, load testing techniques.
6. **🛡️ `@devops-sec`**: Container security, GitOps, zero-trust infrastructure, supply-chain vulnerability scanning, lightning-fast CI/CD.

### Stage 3: Open Floor & User Discussion
* Allow the user to ask questions, challenge ideas, or select which new concepts to incorporate into the codebase.
* Save worthy lessons into project guidelines or technical notes.

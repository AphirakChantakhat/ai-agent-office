## 🌟 Overview

**AI Agent Office** is an enterprise-grade AI software development workspace. It combines an autonomous **6-role specialized engineering team** with an interactive **Real-time 3D Voxel Telemetry Console** and a disciplined **Hybrid Waterfall execution model** featuring human milestone sign-offs.

```
┌────────────────────────────────────────────────────────┐
│  Phase 1: 10:00 AM Standup & Brainstorming (All Roles) │
│  - Team pitches ideas, reviews yesterday's progress    │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  Phase 2: Architectural Design (@architect)            │
│  - System specs, DB schemas, API contracts             │
└──────────────────────────┬─────────────────────────────┘
                           ▼
               [🛑 USER MILESTONE SIGN-OFF 1]
                           ▼
┌────────────────────────────────────────────────────────┐
│  Phase 3: Implementation & Validation                  │
│  - @backend-dev & @frontend-dev build modules          │
│  - @qa-tester validates & tests automatically          │

                           ▼
┌────────────────────────────────────────────────────────┐

│  - Code standards, security review, build verification │
```

## 👥 The 6 Core Engineering Roles

| Role | Identifier | Key Responsibilities |
| :--- | :--- | :--- |
| **PM / Tech Lead** | `@pm-lead` | Facilitates 10:00 AM standup, tracks task queues, and manages Waterfall phase transitions. |
| **System Architect** | `@architect` | Designs system architecture, database schemas, and API contracts before coding. |
| **Frontend Specialist** | `@frontend-dev` | Develops UI/UX components, client-side state, accessibility, and responsive layouts. |
| **Backend Specialist** | `@backend-dev` | Develops REST/GraphQL APIs, business logic, transactions, and database queries. |
| **QA Tester** | `@qa-tester` | Writes automated unit/integration tests, validates edge cases, and verifies bug fixes. |
| **DevOps & Security** | `@devops-sec` | Manages environment configurations, CI/CD pipelines, security audits, and deployment readiness. |

## ⚡ Key Features

1. **🎮 Real-time 3D Voxel Telemetry Console (`http://localhost:3333`)**:
   - Zero-Emoji minimalist aesthetic inspired by Linear and Vercel.
   - High-contrast Dark and Light modes.
   - Active room illumination when an agent is working.
   - Sub-pixel breathing LED indicators and HUD spark badges.
   - Synthesized retro 8-bit sound chimes using the Web Audio API.

2. **🛡️ Multi-Model 3-Tier Zero-Downtime Failover**:
   - Primary tier routes tasks to the best-suited model (Claude Opus 5.5, Claude Sonnet 5.5, Gemini 4 Argon, Gemini 3.8 Flash).
   - Cross-provider fallback cascade ensures uninterrupted work when encountering rate limits or quota caps.

3. **💰 Auto-Eco Protocol (70% Token Savings)**:
   - Dynamic role dispatch wakes only the responsible agent for routine tasks.
   - Dormant roles stay in standby to minimize token usage.

4. **🎯 1-Click Daily Outcome Tracking**:
   - Summarizes daily engineering achievements into ready-to-copy reports for Timesheets, Jira, or Daily Standups.

## 🚀 Quick Start in 1 Step

### Prerequisites
- Node.js (v16 or higher)
- Windows / macOS / Linux

### Run the Telemetry Console
Double-click `start_office.bat` or run:

```bash
node server.js
```

Open your browser at **[http://localhost:3333](http://localhost:3333)** to view the live office dashboard.

## 📋 Slash Commands Quick Reference

| Command | Description |
| :--- | :--- |
| **`/standup`** | Starts the 10:00 AM Daily Standup meeting with all 6 roles. |
| **`/friday-share`** | Starts the Friday continuous tech upskill session. |
| **`/outcome`** | Generates a 3-format Daily Outcome Tracking report ready for timesheets. |
| **`/log-work`** | Logs task completions to `WORK_LOG.md` for seamless context handoffs. |
| **`/resume`** | Resumes progress instantly from `WORK_LOG.md` without re-reading the codebase. |
